# Medical Platform

منصة تعليمية عربية/إنجليزية لإدارة وبيع الكورسات التعليمية، مع تفعيل يدوي للوصول بعد الدفع الخارجي.

## التطبيقات

- `server`: واجهة API مبنية بـ Node.js وExpress وMongoDB.
- `client`: واجهة المستخدم المبنية بـ React.
- `admin`: لوحة تحكم الإدارة المبنية بـ React.

## المتطلبات

- Node.js (إصدار LTS حديث)
- MongoDB يعمل محليًا

## التشغيل المحلي

1. أنشئ ملف `.env` في جذر المشروع باستخدام قيم `.env.example`.
2. شغّل `npm install` داخل كل من `server` و`client` و`admin`.
3. شغّل الـ API من `server`، ثم واجهة المستخدم ولوحة الإدارة كلًّا في طرفية مستقلة.

> سيتم إضافة أوامر التشغيل الدقيقة مع اكتمال مهمة التأسيس.
